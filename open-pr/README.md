# open-pr

Push the current branch and open or update a pull request on GitHub using the `gh` CLI. Detects if a PR already exists for the current branch and updates it instead of creating a duplicate.

## Install

```bash
npx skills@latest add abijith-suresh/skills/open-pr
```

## Use

- "open a PR"
- "create a PR"
- "update my PR"
- "push and open a PR"

Requires the [GitHub CLI (`gh`)](https://cli.github.com/) to be installed and authenticated.
