# tdd

Build features test-first using red-green-refactor. One failing test, minimal code to pass, repeat.

## What This Skill Covers

- **Vertical tracer bullets** — writes one test and its minimal implementation before moving on
- **Behavior-driven testing** — verifies behavior through public interfaces, not implementation details
- **Test pyramid guidance** — prioritizes small fast tests over expensive end-to-end suites
- **Continuous refactoring** — cleans duplication and improves names while the suite is green

- "build this test-first"
- "TDD this"

## How it works

1. **Plan the interface** — confirms method signatures and behaviors before any code is written.
2. **RED** — writes one failing test for the most important behavior.
3. **GREEN** — writes the minimum code to pass that test.
4. **Refactor** — cleans up duplication and improves names.
5. **Repeat** — continues one test at a time until the feature is complete.
