# plan

Explore the relevant codebase state and produce a settled PLAN.md
before writing any code.


## Use

- "create a plan for X"
- "plan this feature out"
- "help me think through this change"
- "I want to build X, let's plan it"

## How it works

1. **Explore** — reads the codebase to understand the current state.
2. **Ask** — presents any open questions with labeled options.
3. **Plan** — produces a structured PLAN.md with implementation steps,
   files to modify, and design decisions.
