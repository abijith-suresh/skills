# plan

Explore the relevant codebase state and produce a settled PLAN.md before writing any code.

## What This Skill Covers

- **Codebase-aware exploration** — inspects current implementation before asking design questions
- **Batch decision-making** — surfaces all open questions at once with labeled options
- **Structured planning** — produces PLAN.md with goal, approach, steps, and testing notes
- **Source file safety** — never modifies code during planning phase

## Install

```bash
npx skills add abijith-suresh/skills --skill plan
```

## Use

- "create a plan for X"
- "plan this feature out"
- "help me think through this change"
- "I want to build X, let's plan it"

## How it works

1. **Explore** — reads the codebase to understand the current state.
2. **Ask** — presents any open questions with labeled options.
3. **Plan** — produces a structured PLAN.md with implementation steps, files to modify, and design decisions.
