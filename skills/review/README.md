# review

Review code changes and write a structured REVIEW.md. Supports standard diff review and story-aware review.

## Install

```bash
npx skills add abijith-suresh/skills --skill review
```

## Use

- "review my changes"
- "do a code review"
- "review this branch"
- "review against the story [description]"
- "check if this branch covers everything for [bug/story]"
